# Telegram-бот для командных задач

Минимальный пример на Python 3.10+, aiogram 3 и встроенном sqlite3.
Код содержит комментарии для начинающих.

## Запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather), команда `/newbot`, и получите токен.

2. Выполните в папке проекта:
   
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env
   ```

3. В `.env` замените `your_bot_token_here` своим токеном. Не публикуйте этот файл.

4. Запустите:
   
   ```bash
   python main.py
   ```

Если на Ubuntu/Debian создание окружения завершается ошибкой `ensurepip is not
available`, установите системный пакет `python3-venv` (для конкретной версии
Python может понадобиться, например, `python3.14-venv`) и повторите команду.

База `data/tasks.db` и таблица `tasks` создаются автоматически.
Остановить бота можно сочетанием Ctrl+C. Задачи сохранятся после перезапуска.

## Подключение через VLESS

Запустите VLESS-клиент и включите в нём локальный SOCKS5 или HTTP-прокси.
В `.env` укажите адрес и порт из настроек клиента:

```dotenv
TELEGRAM_PROXY_URL=socks5://127.0.0.1:1080
```

`1080` — пример, замените его портом своего клиента. Для HTTP используйте
`http://127.0.0.1:ПОРТ`. Если прокси требует авторизацию, формат адреса:
`socks5://логин:пароль@127.0.0.1:ПОРТ` (специальные символы кодируются как в URL).
Ссылку `vless://...` импортируют в VLESS-клиент, а бот подключается к его
локальному прокси. Все запросы бота, включая получение обновлений и отправку
CSV, используют эту сессию. При недоступности заданного прокси прямого
подключения не будет.

Если клиент работает в режиме TUN и маршрутизирует трафик бота, оставьте
`TELEGRAM_PROXY_URL` пустой. После изменения `.env` перезапустите бота.
После обновления проекта снова выполните `pip install -r requirements.txt`.

## Команды

| Команда                  | Действие                                                      |
| ------------------------ | ------------------------------------------------------------- |
| `/start`                 | Приветствие и инструкция                                      |
| `/add Подготовить отчёт` | Сохраняет задачу с автором и временем                         |
| `/list`                  | Показывает все задачи, разбивая длинный список на сообщения   |
| `/list_csv`              | Отправляет `tasks.csv`; для пустого списка — только заголовок |

`/add` без текста показывает пример ввода. В группах можно использовать
`/add@имя_бота текст задачи`. CSV отправляется в чат, где вызвана команда.
Время сохраняется в UTC. CSV использует UTF-8 с BOM и стандартное экранирование
кавычек, запятых и переносов строк; значения, похожие на формулы, получают апостроф.

Это один общий список для всех пользователей и чатов этого экземпляра бота.
Разделения по командам и проверки доступа нет: используйте его в доверенной команде.

## Структура

```text
main.py                 # запуск бота
bot/
  config.py             # настройки
  handlers/tasks.py     # обработчики команд
  database/tasks.py     # создание таблицы, INSERT и SELECT
  keyboards/__init__.py # меню команд Telegram
  services/export.py    # CSV и разбивка длинных сообщений
requirements.txt        # зависимости
.env.example            # пример настроек
```

SQLite-операции выполняются через `asyncio.to_thread`, а соединение открывается
на каждую операцию. SQL-запросы используют параметры вместо вставки текста в SQL.
